# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-14
- Issue: #8

## Context

Agents and humans work on this repository. They need the reasons for past decisions.

## Decision

We record significant decisions as short ADRs in `docs/decisions/`. We do not edit accepted ADRs;
a new ADR supersedes an old one.

## Consequences

Each PR that changes architecture, tooling, or a dependency strategy includes an ADR.
